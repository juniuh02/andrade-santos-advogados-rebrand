# Andrade Santos Advogados — Landing Page

Esta pasta contém tudo o que é necessário para publicar a landing page no GitHub Pages.

## Publicação

1. Envie **o conteúdo desta pasta** para a raiz do repositório no GitHub.
2. No repositório, acesse **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch principal (`main`) e a pasta **/ (root)**.
5. Salve e aguarde o GitHub informar a URL publicada.

O arquivo de entrada é `index.html`. Os recursos locais estão em `assets/` e as bibliotecas de animação em `vendor/`.
